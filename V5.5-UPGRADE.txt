420VaultBot v5.5.0 — Feature Patch

NEW
- 420_user_manual: built-in interactive user manual GUI.
- 420_admin_manual: built-in admin/operator manual GUI (admin only).
- Physical Vault audio preview actions. Files that fit Discord are previewed directly; large audio can use a 30-second MP3 preview when FFmpeg is installed.
- Live web scraper dashboard: pages, unique links, errors, queue, current page, and recent discovered URLs refresh during the crawl.
- Persistent Physical Vault index policy: full scans no longer wipe the index first; unseen items are marked unavailable rather than deleted.
- Expanded randomized TOS question pool. Each session samples questions and shuffles answers.
- Remote File Servers admin section using configurable HTTPS JSON manifests.
- 420_server_search for indexed remote-server files and server-hosted download/preview URLs.
- Version moved to 5.5.0 throughout the live application.

REMOTE SERVER MANIFEST FORMAT
[
  {"name":"Example.wav","path":"Audio/Example.wav","size":123456,"download_url":"https://files.example.com/Audio/Example.wav","preview_url":"https://files.example.com/previews/Example.mp3"}
]
Or: {"files":[ ...same objects... ]}

SECURITY
- Remote manifest URLs must use HTTPS in the Discord admin configuration.
- Optional bearer token is stored in SQLite and sent only to the configured manifest endpoint. For high-security deployments, protect the database and host filesystem.
- Direct download/preview URLs are revealed only after normal 420Vault command access checks.

NOTES
- FFmpeg is optional. It is only needed to transcode oversized local audio into a short preview.
- Existing v4.9 Google Drive, subscriptions, licensing, Terms, tickets, Link Library, and Physical Vault workflows remain present.
