420VaultBot v5.5.1 — Google Drive Archive Search

Admin workflow:
1. Sync Google Drive metadata normally.
2. Admin GUI -> Google Drive -> Parse ZIP/RAR.
3. The parser temporarily downloads eligible .zip/.rar files, reads their member filenames, indexes those names, and removes the temporary local copy.
4. 420_drive_search now searches ordinary Drive names/paths AND parsed archive member names/paths.
5. Selecting a result found inside an archive delivers the FULL ORIGINAL ZIP/RAR from Google Drive. It does not extract or deliver only the member.

Safety/performance:
- Parsing is opt-in; it is NOT automatically done during every Drive metadata sync.
- Default maximum archive size to parse is 2 GiB per archive. Override with GOOGLE_DRIVE_ARCHIVE_PARSE_MAX_BYTES.
- Archive parsing uses temporary disk space and Drive bandwidth.
- ZIP parsing uses Python zipfile. RAR filename listing uses rarfile.
- Existing Drive link-priority and Discord upload-limit behavior is retained.
