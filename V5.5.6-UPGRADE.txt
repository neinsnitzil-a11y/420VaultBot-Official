420VaultBot v5.5.6

- SQLite concurrency hardening: serialized connection access, WAL-compatible 30s busy timeout, worker-thread DB operations in live scraper.
- Live scraper acknowledges immediately and updates the Discord dashboard while crawling.
- Restricted accounts (new/unverified/unpaid/expired) only see/use 420_help, 420_subscribe, 420_user_manual. Protected command attempts show Not Authorized + subscription GUI.
- Physical Vault audio browser retains Preview Audio before Download Original.
- Google Drive ZIP/RAR parsed results return the full parent archive; Drive folders can be browsed/opened or recursively packaged as ZIP for Discord when within upload limit.
- #license-generator is created/reused at bootstrap with an admin-only License Generator GUI. Admin selects the customer, then generates; license + activation GUI are sent to the selected customer DM.
- GUI-issued licenses receive ORD-... order IDs stored in license_orders.
- Complete user PDF ships at docs/420VaultBot_User_Manual_v5.5.6.pdf and is available from 420_user_manual.
- Heartbeat/watchdog from v5.5.5 retained.

UPGRADE NOTE: keep your existing .env and data/420vault.db when replacing application files. Do not overwrite your live data directory with a clean distribution.
