420VaultBot v4.8.0 — Responsiveness Overhaul

IMPORTANT: This release package intentionally does not contain your private runtime database,
Google OAuth secret JSON, .env, or virtual environment.

To upgrade from your existing bot:
1. Stop every old 420VaultBot process.
2. Extract v4.8 to a new folder.
3. Copy your existing .env into the v4.8 folder (if you use one).
4. Copy your existing data/420vault.db into v4.8/data/ to preserve server settings/indexes.
5. Copy data/google_drive_secrets.json only if you want to preserve the OAuth credentials already entered through the Admin GUI.
6. Start v4.8 with run.bat.
7. Open 420_admin -> Google Drive -> Status, then Sync Metadata.
8. While syncing, test 420_help / 420_admin / Status. They should remain responsive.

Do not run v4.7 and v4.8 against the same SQLite database at the same time.
